# НИЦ СМК — автоматизация документов

Веб-приложение для строительной лаборатории и службы строительного контроля:
объекты, фото с подписями ИИ, акты отбора, протоколы испытаний, отчёты, КП.

## Что умеет

- **Объекты** — создаются загрузкой проектной документации (PDF/DOCX/XLSX/фото/ZIP).
  ИИ читает документы (включая сканы через профиль «Фото»), заполняет наименование,
  адрес, заказчика, подрядчика, контракт и группирует объект по округу.
- **Поле** — специалист выбирает объект (список по округам), снимает фото, пишет
  комментарий; ИИ автоматически подписывает фото. Акты отбора проб с подписью пальцем.
- **Лаборатория** — протоколы испытаний (бетон, асфальт и др.) с расчётом и PDF.
- **Отчёты** — недельные, итоговые, отчёт строительного контроля; сбор данных из объекта.
- **КП** — коммерческие и госзакупочные (АБ, АБ ЕВРО, СК) от трёх компаний,
  калькуляторы пакетов и по площади.
- **Роли** — администратор, инженер СК, руководитель лаборатории, наблюдатель.
- **Хранение** — локально (SQLite + файлы) или на облачном сервере; ежедневные резервные копии.

## Запуск на компьютере

```bat
Запуск (автоперезапуск).bat
```

Откроется http://127.0.0.1:8765. Первый вход: `admin` / `1234` (смените пин).

## Запуск на сервере

Смотрите `deploy/DEPLOY.md`: Docker + Caddy (HTTPS), домен, перенос данных, бэкапы.

## ИИ

Настройки → Искусственный интеллект. Два профиля:
- **Текст** — DeepSeek / ProxyAPI / любой OpenAI-совместимый;
- **Фото** — модель с поддержкой изображений (GPT-4o-mini через ProxyAPI).

Без ключа программа работает, но без генерации текстов и распознавания фото/сканов.

## Структура

```
server.py          HTTP-сервер и API
app/               логика: объекты, протоколы, отчёты, КП, ИИ, хранилище
static/            интерфейс (SPA, PWA)
deploy/            Docker, Caddy, инструкция по серверу
```
